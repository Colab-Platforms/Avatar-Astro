# aspects-geometry

Calculate and interpret all astrological aspects between planets — major aspects (conjunction, opposition, trine, square, sextile) and minor aspects (semi-sextile, quincunx, semi-square, sesquiquadrate, quintile, bi-quintile). Includes orb tables, aspect pattern recognition (Grand Trine, T-Square, Grand Cross, Yod, Kite, Mystic Rectangle, Stellium, Thor's Hammer), and midpoint analysis (cosmobiology). Use when interpreting how planets relate to each other in any chart type.
