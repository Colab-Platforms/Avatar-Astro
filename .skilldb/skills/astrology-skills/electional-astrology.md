# electional-astrology

Electional astrology — choosing the optimal date and time to begin an activity based on astrological conditions. Covers election chart rules, planetary hours, Moon conditions (void-of-course, lunar mansions, applying aspects), benefic/malefic timing, Mercury retrograde avoidance, and elections for specific activities (business launch, wedding, surgery, travel, contracts, moving, job start). Use when the user wants to find the best time to start something or wants to know if a specific date is astrologically favorable.
