# harmonics-custom-charts

Harmonic charts (1st through any harmonic), bi-wheel chart overlays, tri-wheel charts, quadri-wheel charts, and custom chart generation. Covers harmonic astrology theory (John Addey), harmonic calculation, interpretation of specific harmonics (H4 for squares, H5 for quintiles, H7 for septiles, H9 for navamsa/noviles), and multi-chart overlay techniques for comparing natal, progressed, transit, and return charts simultaneously. Use when the user wants harmonic charts, multi-wheel displays, or custom chart configurations.
